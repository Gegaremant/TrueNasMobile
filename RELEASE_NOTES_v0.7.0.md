# TrueNasMobile v0.7.0-Alpha — Августовский обзор 🚀

Привет, r/TrueNAS и r/selfhosted! Вышел огромный апдейт TrueNasMobile (Android-приложения для управления TrueNAS).

## Что нового

### 🔍 Поиск по всему приложению
Нажмите на значок поиска в любой вкладке — ищите по всему инстансу TrueNAS:
- **Установленные приложения** — по имени, названию, описанию, категориям, ключевым словам
- **Каталог Marketplace** — запросы в реальном времени из TrueNAS, реальные иконки приложений
- **Пулы хранения, диски, шары** — поиск по имени, пути, модели, серийному номеру
- **Контейнеры и ВМ** — поиск по имени, статусу, характеристикам
- **30+ экранов и разделов** — введите «сеть», «пользователи», «обновление» и перейдите прямо туда
- **Сетка быстрых действий** при пустом запросе — быстрые переходы к настройкам инстанса, API-ключам, Marketplace и т.д.
- **Недавние запросы** с удалением по одному и очисткой всех

### 🔐 Двухфакторная аутентификация MFA / TOTP
TrueNasMobile теперь поддерживает учётные записи TrueNAS с включённой 2FA:
- Полный поток TOTP: ввод учётных данных → страница OTP появляется автоматически
- Автовход после холодного старта для пользователей TOTP — данные проверены, страница OTP показана сразу
- Восстановление сессии с автоматической повторной аутентификацией
- Отправка по Enter в полях пароля/API-ключа

### ⚡ Производительность
- Главный экран стал заметно плавнее — убраны тяжёлые анимированные индикаторы, вызывавшие подтормаживания
- Количество API-вызовов при старте снижено на 60%
- Статические фоны на экранах входа/настройки (никакой бесконечной рекомпозиции анимаций)

### 🎨 Полировка интерфейса
- Чипы-пилюли на главном экране: Обновление → Производительность → Настройки инстанса → Информация о системе (горизонтальная прокрутка)
- Иконки приложений в результатах поиска
- Плавный переход от входа к главному экрану без вспышки
- Страница OTP в полном стиле Material 3 с волнистым фоном
