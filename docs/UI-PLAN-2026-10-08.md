# План доработки — 2026-10-04, раунд 3 (после 1.0.8)

## Быстрые правки (в этом заходе)

1. [ ] **Профиль — это не NAS.** Сейчас учётка живёт внутри NAS (у NAS
   список учёток). Нужно наоборот: у пользователя список подключений, у каждого
   своё. Требует миграции хранилища и правки экрана переключения.
2. [x] **Цвета графиков — по «нормальности».** Сейчас цвет задан темой
   (синий/фиолетовый/красный независимо от значения). Нужно: низкая нагрузка —
   спокойный синий, средняя — жёлтый, высокая — розовый/красный.
3. [x] **Переключение наоборот.** Короткое нажатие на иконку профиля → список
   NAS с быстрым переключением; **долгое** → создание ещё одной учётки.
   Сейчас ровно наоборот.
4. [ ] **Мониторинг всех NAS сразу**, а не только выбранного, и оповещения
   от всех подключений. Требует п.1: пока один профиль — один NAS.
5. [ ] **Оповещения без деталей.** Прилетает «резервное копирование не
   прошло» и всё: что именно не так — не видно. Нужен полный текст ошибки из
   задачи. Плюс сами задачи по расписанию (синхронизация, резервирование) —
   они сейчас не видны вообще.
6. [x] **Иконка настроек приложения непонятна.** Робот с шестерёнкой не читается
   как «настройки приложения», особенно рядом с настройками NAS (ящик с
   шестерёнкой). Нужна ясная иконка.
7. [x] **Бесконечный кружок при обрыве связи.** Вместо вечного спиннера —
   честное сообщение, что сервер недоступен, с адресом и кнопкой повтора.
8. [x] **Убрать «О приложении» и «Лицензии»** из настроек. Лицензии нет,
   разработчик один — незачем занимать два пункта меню.
