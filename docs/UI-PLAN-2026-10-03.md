# План доработки UI — 2026-10-03

Список правок из обратной связи по 1.0.5. Порядок = порядок работы.

## A. Баги

1. [x] **Метрики «в реальном времени» показывали мусор вместо значений.**
   CPU — «1753567890123%», температура — миллиарды градусов. Причина:
   `DetailsMetricsSection.currentValueLabel()` брала `point.firstOrNull()`, а
   первая колонка точки `system.report` — это Unix-таймстамп в миллисекундах.
   Теперь CPU = среднее по ядрам (`drop(1).average()`, кламп 0..100),
   память = `getOrNull(1)` в ГБ, температура = `getOrNull(1)`.
2. [ ] **Верхнее и нижнее меню пропадают на экране «Общие ресурсы»**
   (нужна и шапка, и нижняя навигация — как на остальных вкладках).

## B. Шапка

3. [ ] **Верхняя строка (бренд) адаптивна под устройство.**
   Сейчас один размер шрифта на всех экранах. Требование: если камера попадает в
   вырез — надпись не должна под неё заезжать (уменьшаем/разбиваем на две
   части по бокам от выреза), если вырез ниже строки — просто крупнее шрифт.
4. [ ] **Вторая строка (управление) не влезает на узком экране.**
   На узких экранах помещаются название + 2 иконки слева и 2 справа, третья и
   четвёртая выпадают. Нужна адаптивная компоновка (прокрутка/перенос/сжатие).
5. [ ] **Шапка всегда на одном месте** независимо от вкладки — сейчас в «Задачах»
   переключатель под-вкладок стоит **выше** шапки.

## C. Профиль и аккаунты

6. [ ] **В шапке — аватарка по центру** (первая буква имени, если аватара нет),
   независимо от длины названия профиля.
   - Короткое нажатие → страница аккаунтов/добавления.
   - Долгое нажатие → список аккаунтов для мгновенного переключения
     (без отдельного меню переключения).
7. [ ] **Страница аккаунтов:** добавление нового пользователя на тот же NAS ИЛИ
   другого NAS; нажатие на существующий аккаунт → редактор (логин, пароль и пр.).
