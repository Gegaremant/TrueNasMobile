   Улучшить кэширование в приложении (ответы API, объединённые данные, изображения, данные инстансов), чтобы уменьшить сетевой трафик и ускорить загрузку экранов.

   Сделать переключение между сохранёнными учётными записями TrueNAS плавнее и предзагружать данные других учётных записей в фоне, чтобы переключение было мгновенным.

   Сейчас поиск не возвращает на предыдущую страницу (по умолчанию ведёт на главный экран или закрывается некорректно). Исправить обратную навигацию и закрытие поисковой панели.

   Экран производительности должен подстраивать интервал опроса в зависимости от выбранного показателя/масштаба времени (например, опрашивать чаще для коротких интервалов, реже — для длинных).

   Страница лицензий показывает только лицензию самого приложения (GPL-3.0) с честной подписью «App License». Если нужны лицензии зависимостей — сгенерировать полный список.

## Найдено аудитом перед релизом 1.0.2 — осознанно не исправлено

Ниже реальные находы проверки функциональности, которые НЕ починены в 1.0.2,
потому что требуют продуктового решения или заметной работы. Порядок — по
убыванию важности.

### Требует решения

11. **Нижняя навигация игнорирует настройки пользователя**
    `MainScreen.kt` жёстко задаёт `FIXED_NAV_DESTINATIONS = [Home, Storage,
    Tasks, Performance]`. Вся подсистема `PersonalizationManager.navbarDestinations`
    вместе с `NavbarDestination` (сохранение, `availableDestinations`,
    `effectiveDestinations`) существует, но **не имеет ни одного вызова**:
    настройки пишутся на диск и никогда не читаются. Нужно либо подключить, либо
    удалить. Побочный эффект: Приложения, Контейнеры, ВМ, Настройки инстанса,
    Обновления и Marketplace сейчас доступны только через поиск.

12. **«True OLED black» недостижим**
    `MainActivity.kt` читает `personalization.blackMode`, но
    `PersonalizationManager.saveBlackMode()` не вызывается нигде, и тумблера в
    `ThemeScreen` нет. При этом две подписи в UI обещают эту функцию
    (`SettingsScreen.kt`, `InstanceConfigScreen.kt`). Либо добавить переключатель,
    либо убрать обещание из UI.

13. **Профиль пользователя — осиротевшая фича**
    `ui/profile/ProfileScreen.kt` + `ProfileViewModel.kt` + `UiState.kt`
    (562 строки) полностью написаны и не подключены: ни в навграфе, ни в одном
    вызове. Либо подключить к навигации, либо удалить.

14. **Экран локального администратора недостижим**
    `Screen.LocalAdminSetupScreen` зарегистрирован как destination, но
    `navController.navigate` к нему не вызывается ни разу. Из-за этого мёртвы
    `SystemService.setupLocalAdministratorWithResult` и
    `hasLocalAdministratorSetUpWithResult`.

15. **minSdk = 33 (Android 14) — возможная причина жалобы «версия несовместима»**
    Пользователи с Android ниже 14 не установят приложение вообще. Если нужна
    широкая аудитория — понизить minSdk (например, до 29) и проверить сборку.
    Это продуктовое решение, в 1.0.2 не менялось.

### Баги

16. **Тяга Docker-образа: гонка с обновлением списка**
    `DockerImageListScreen.kt` — pull отправляет асинхронную задачу, затем сразу
    вызывает `refresh()`. Список обычно обновляется раньше, чем задача
    завершится, и пользователь не видит результата. Нужен трекинг job id
    (как в `JobNotificationService`) либо опрос статуса.

17. **`PersonalizationManager.currentUserKey()` игнорирует свой параметр**
    Всегда возвращает `DEFAULT_USER_KEY`, хотя KDoc обещает «последний
    использованный профиль». Все учётные записи делят одну корзину настроек —
    выбор темы утекает между аккаунтами.

18. **`ApiResult.Loading` в `when` без обработки — около 25 мест**
    (`AppsScreenViewModel`, `ContainerScreenViewModel`, `VmsScreenViewModel` и др.)
    Сейчас `callWithResult` не возвращает `Loading`, поэтому баг латентный, но при
    `deleteApp` / `upgrade` пользователь не получит ни отклика, ни обновления
    списка.

19. **`TrueNasMobileLogger.isLoggingEnabled` — сеттер молча игнорирует записи**
    (`data/helpers/TrueNasMobileLogger.kt:16-18`). Сейчас никто не пишет, но это
    ловушка.

20. **`Appcache.clearAllCache()` не чистит `cachedMarketplaceApps` и `cachedServices`**
    После выхода из учётной записи остаются устаревшие данные маркетплейса и
    служб.

21. **Маршрут обновления системы может остаться пустым**
    Если `isLoading == false`, `summary == null` и `uiState.error == null`, не
    отрисовывается ни одна ветка — пустой экран без выхода.
