# TrueNasMobile — Бэклог / TODO

Задачи для будущих сессий разработки. Берите по порядку при выборе новой задачи.

1. **Улучшение кэширования по всему приложению**
   Улучшить кэширование в приложении (ответы API, объединённые данные, изображения, данные инстансов), чтобы уменьшить сетевой трафик и ускорить загрузку экранов.

2. **Более быстрое переключение учётных записей и предзагрузка остальных**
   Сделать переключение между сохранёнными учётными записями TrueNAS плавнее и предзагружать данные других учётных записей в фоне, чтобы переключение было мгновенным.

3. **Больше виджетов**
   Добавить дополнительные виджеты на главный экран помимо существующих: Быстрый запуск / Обновления приложений / Хранилища.

4. **Исправить навигацию в поиске**
   Сейчас поиск не возвращает на предыдущую страницу (по умолчанию ведёт на главный экран или закрывается некорректно). Исправить обратную навигацию и закрытие поисковой панели.

5. **Динамический опрос производительности в зависимости от выбранного фильтра**
   Экран производительности должен подстраивать интервал опроса в зависимости от выбранного показателя/масштаба времени (например, опрашивать чаще для коротких интервалов, реже — для длинных).

6. **Вход по отпечатку пальца в разделе «Конфиденциальность»**
   Добавить опцию биометрической (по отпечатку пальца) аутентификации в Настройки → Конфиденциальность (защита чувствительных действий/информации).

7. **Добавить профиль пользователя**
   Показывать информацию о текущем вошедшем пользователе (имя, данные учётной записи) в подходящем месте (экран профиля).

8. **Исправить страницу лицензий**
   Страница лицензий сломана/неполна; исправить загрузку данных и отображение лицензий open-source.

9. **Разобраться с монтированием шаров или доступом к ним из приложения**
   Изучить возможность монтирования или прямого доступа к шарам TrueNAS из приложения (SMB/NFS) или их внешнего открытия.

10. **Полный перевод интерфейса на русский**
    Ресурсные строки и README уже на русском по умолчанию, но большинство текстов UI захардкожено на английском в Compose-коде (~1,5 тыс. строк по 90+ файлам). Перевести по экранам: логин/настройка, главная, приложения, контейнеры, ВМ, пулы, датасеты, настройки, push.
