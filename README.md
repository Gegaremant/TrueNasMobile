# TrueNasMobile

**Нативный Android-клиент для управления TrueNAS. Просто, быстро, с телефона.**

**⬇️ [Скачать последний релиз](https://github.com/Gegaremant/TrueNasMobile/releases/latest)** · Android 10+

TrueNAS — это отличная система для хранения данных и домашних серверов. Но есть одна большая несправедливость: нормального нативного приложения для неё так и не появилось. Смотреть за сервером через браузер на маленьком экране неудобно, а те две версии клиентов, которые существуют (NasDesk и TrueHub), далеко не покрывают всех возможностей.

Поэтому мы решили сделать своё приложение — своими силами, вдохновившись этими двумя проектами. TrueNasMobile создан с нуля как современное нативное приложение, в котором есть то, чего нам самим не хватало: быстрый доступ к контейнерам, честные графики производительности и управление всем NAS без браузера.

Проект вдохновлён NasDesk и TrueHub.

## Возможности

- **Приложения**
  - Установка из каталога (включая дополнительные экземпляры)
  - Запуск / остановка / перезапуск
  - Обновление и откат версии
  - Просмотр деталей и редактирование конфигурации
  - Удаление приложений
- **Контейнеры**
  - Запуск / остановка
  - Просмотр состояния и деталей
- **Виртуальные машины**
  - Запуск / остановка / завершение работы
  - Просмотр состояния и деталей
- **Хранилище**
  - Просмотр пулов и датасетов
  - Мониторинг использования
- **Производительность**
  - Графики нагрузки в реальном времени (CPU, память, сеть, диски)
  - Общий дашборд состояния системы
- **Уведомления**
  - Push-уведомления о важных событиях NAS
  - Лента предупреждений и алертов системы
- **Поиск**
  - Мгновенный поиск по всему серверу из любой точки приложения
- **Виджеты на рабочий стол**
  - Быстрый запуск приложений
  - Сводка пулов
  - Обновления приложений
- **Безопасность**
  - Вход по API-ключу, паролю и 2FA
  - Биометрическая блокировка приложения
- **Несколько серверов**
  - Управление несколькими инстансами TrueNAS одновременно

## Сборка из исходников

Требования:

- JDK 17+
- Android SDK (compileSdk 37 / targetSdk 37)
- Минимум: Android 10 (minSdk 29)

Сборка:

```bash
git clone https://github.com/Gegaremant/TrueNasMobile.git
cd TrueNasMobile
./gradlew assembleGithubDebug      # для разработки, подпись не нужна
```

Релизная сборка требует ключа подписи. Все секреты лежат в `.env` в корне
репозитория (он в `.gitignore`):

```bash
cp .env.example .env && chmod 600 .env   # заполнить KEYSTORE_* 
./gradlew assembleGithubRelease
```

Готовые APK появятся в `app/build/outputs/apk/github/release/` — по одному на
каждую архитектуру. Полный процесс релиза: [`docs/RELEASE.md`](docs/RELEASE.md).

## Проверки

```bash
./gradlew :app:testGithubDebugUnitTest   # 39 юнит-тестов, ~40 с, без устройства
./gradlew :app:verifyRelease             # сборка релиза + тесты + lintVital
scripts/smoke-device.sh                 # установка на устройство и проверка, что оно живо
```

Что покрыто и — важнее — что не покрыто, описано в
[`docs/TESTING.md`](docs/TESTING.md). Там же объясняется, почему 1.0.2 прошёл
все проверки и при этом закрывался после входа в учётную запись.

## Локализация

Приложение следует системному языку: английский и русский. Весь пользовательский
текст лежит в файлах-словарях локалей
(`res/values/strings.xml` и `res/values-ru/strings.xml`) — в коде его нет.
Правила и проверки: [`docs/LOCALIZATION.md`](docs/LOCALIZATION.md).
