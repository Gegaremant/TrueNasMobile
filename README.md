TrueNasMobile — это открытое Android-приложение, созданное для удобного и интуитивного управления сервером TrueNAS SCALE прямо с телефона. Следите за производительностью, управляйте приложениями и оставайтесь в курсе предупреждений — всё без браузера.

## Возможности
1. Управление приложениями:
   1. Обновление
   2. Запуск / Остановка
   3. Просмотр деталей
   4. Откат версии
   5. Установка приложений (включая дополнительные экземпляры)
   6. Редактирование конфигурации
   7. Удаление приложений
   8. Просмотр каталога
2. Управление контейнерами:
   1. Запуск / Остановка
   2. Просмотр деталей
3. Управление виртуальными машинами:
   1. Запуск / Остановка ВМ
   2. Просмотр деталей
   3. Завершение работы ВМ

## Начало работы

### Для пользователей

Самый простой способ — скачать последний релиз.

1. Перейдите на **[страницу релизов](https://github.com/Gegaremant/TrueNasMobile/releases)**.
2. Скачайте последний файл `.apk`.
3. Откройте файл на своём Android-устройстве и следуйте инструкциям по установке. Возможно, потребуется разрешить установку приложений из неизвестных источников.

### Для разработчиков

Если вы хотите собрать приложение из исходников:

1. **Клонируйте репозиторий**
2. **Откройте его в Android Studio**
3. **Соберите проект** (после синхронизации с Gradle)
